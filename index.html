How to Play

🤖 AI Questions: Every game generates fresh questions using Gemini AI — Nepal-focused (movies, sports, politics, culture) plus international knowledge. No repeats!


🧠 Solo Mode: Answer 15 questions, climb the prize ladder to Rs. 1 Crore. One wrong answer ends the game (safe havens at Q5 & Q11).


👥 Multiplayer: Min 15 questions. Everyone answers simultaneously — faster correct answers earn bonus points.


⏱️ 30 seconds per question. Use 3 lifelines in solo: 50:50, Phone a Friend, Audience Poll.

⚠️
Firebase Setup Needed
Multiplayer requires a free Firebase Realtime Database.

1. Go to console.firebase.google.com
2. Create project → Enable Realtime Database
3. Set Database Rules: read & write = true
4. Replace FIREBASE_CONFIG in the code

Solo mode works without any setup!
🔑
Fix Your Gemini API Key
Your key has domain restrictions blocking it from working in the browser.

Fix in 30 seconds:

1. Go to console.cloud.google.com/apis/credentials
2. Click on your API key named "game"
3. Under Application restrictions → select "None"
4. Click Save

OR create a brand new unrestricted key at:
aistudio.google.com/apikey
