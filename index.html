How to Play

🤖 AI Questions: Every game generates brand-new questions using Claude AI — you'll never see repeats! Covers Nepal & world topics.


🧠 Solo Mode: Answer 15 questions across General, Movies, Sports, Politics & World. Climb the prize ladder up to Rs. 1 Crore!


👥 Multiplayer: Create a room, share the 6-digit code. Everyone answers simultaneously — faster correct answers earn bonus points!


⏱️ 30 seconds per question. Use your 3 lifelines wisely: 50:50, Phone a Friend, and Audience Poll.


🔑 Setup: Add your free Anthropic API key under "API Key Setup" to enable AI questions.

🔑
API Key Needed
To generate AI-powered questions, you need a free Anthropic API key.

1. Go to console.anthropic.com
2. Create an account → go to API Keys
3. Create a key (starts with "sk-ant-")
4. Paste it in the API Key Setup screen
⚠️
Firebase Setup Needed
Multiplayer requires a free Firebase Realtime Database.

1. Go to console.firebase.google.com
2. Create a new project → Enable Realtime Database
3. Set Rules: read & write to true
4. Replace the FIREBASE_CONFIG in the script section

Solo mode works without Firebase!
