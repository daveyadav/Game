How to Play

🧠 Solo Mode: Answer 15 Nepal-based questions across General Knowledge, Movies, Sports & Politics. Climb the prize ladder up to Rs. 1 Crore! One wrong answer — you leave with your safe haven amount.


👥 Multiplayer: Create a room and share the 6-digit code. Everyone answers simultaneously — faster correct answers earn bonus points!


⏱️ 30 seconds per question. Use your 3 lifelines wisely: 50:50, Phone a Friend, and Audience Poll.


🔒 Safe Havens at Q5 (Rs. 10,000) and Q11 (Rs. 6,40,000) — you keep this even if you answer wrong after.

⚠️
Firebase Setup Needed
Multiplayer requires a free Firebase Realtime Database.

1. Go to console.firebase.google.com
2. Create a new project → Enable Realtime Database
3. Set Database Rules: both read & write to true
4. Copy your config and replace the FIREBASE_CONFIG object at the top of index.html
5. Re-deploy to GitHub Pages

Solo mode works without any setup!
